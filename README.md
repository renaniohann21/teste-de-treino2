Teste de Treino 2 - FitForge
Este e um projeto de estudo e pratica de desenvolvimento web frontend, criado para testar e aprimorar conceitos fundamentais de HTML, CSS e JavaScript. A aplicacao e o FitForge, um gerador de treinos personalizados.
Tecnologias Utilizadas
O projeto foi desenvolvido utilizando as seguintes tecnologias:
HTML5: Estruturacao das paginas e elementos da interface.
CSS3: Estilizacao, layout responsivo e variaveis de tema.
JavaScript (ES6+): Manipulacao de DOM, eventos e logica do gerador de treinos.
Estrutura de Arquivos
teste-de-treino2/
├── index.html   # Estrutura principal da aplicacao
├── style.css    # Estilos e temas visuais
└── main.js      # Logica de criacao do plano e interacoes


Como Executar o Projeto
Clonar o repositorio:
git clone https://github.com/seu-usuario/teste-de-treino2.git


Navegar ate a pasta do projeto:
cd teste-de-treino2


Abrir o projeto:
Abra o arquivo index.html diretamente em qualquer navegador.
Ou utilize a extensao Live Server no VS Code para executar em um servidor local.
